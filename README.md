# omnisign/entrust

**Reserved, not released yet.**

Entrust Identity Verification (formerly Onfido) for omnisense/omnisign: identity verification (a document, a selfie, liveness), under a contract with Entrust; a sandbox. The family's `identity-check` contract (`IdentityCheckInterface`, since omnisense/omnisign
1.1) is what it will keep, as [`omnisign/stripe-identity`](https://github.com/glitchr-omnisense/omnisign-stripe-identity) does.

The name is kept for the provider package; nothing is released under it yet. A maintainer is
wanted: see the site's [contribute page](https://glitchr-omnisense.github.io/omnisense/contribute).
